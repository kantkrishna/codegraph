# Codegraph: Enterprise Developer Intelligence Platform
AI-Augmented Engineering Platform that continuously understands enterprise software systems by ingesting repositories and documentation, constructing a Knowledge Graph and Hybrid RAG index, and exposing multiple interfaces for engineering intelligence.

## Local Development
This project uses `uv` for dependency management.
1. Install `uv`: `curl -LsSf https://astral.sh/uv/install.sh | sh`
2. Sync dependencies: `uv sync`
3. Activate virtual environment: `source .venv/bin/activate`
